# mountainfronts-vr-demo
3D sketch of how Smf classes could be shown in VR, linking mountain fronts to the faults beneath them
The left block shows a straight Class 1 front sitting above a thrust fault that is still moving. The right block shows a sinuous Class 3 front above a fault that has stopped and is buried under sediment. The "Look underground" button makes the ground see-through so you can see the fault planes under each front.

The terrain is made up to show the idea. A real version would use a DEM and satellite imagery from the Andes, with Smf values from Heidi Daxberger's PhD thesis.
